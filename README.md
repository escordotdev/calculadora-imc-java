# Calculadora de IMC, TMB e GET

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação e desenvolver uma aplicação interativa via terminal.

## Sobre o projeto

A aplicação permite que o usuário informe seus dados físicos e receba cálculos relacionados à composição corporal e ao gasto energético diário.

## Funcionalidades

- Cálculo do Índice de Massa Corporal (IMC).
- Estimativa do percentual de gordura corporal.
- Cálculo da Taxa de Metabolismo Basal (TMB).
- Cálculo do Gasto Energético Total (GET).
- Seleção de sexo.
- Seleção de nível de atividade física.
- Entrada de altura utilizando vírgula ou ponto como separador decimal.
