# Calculadora de IMC, Percentual de Gordura, TMB e GET

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação e desenvolver uma aplicação interativa executada pelo terminal.

## Sobre o projeto

A aplicação permite que o usuário informe seus dados físicos e receba estimativas relacionadas ao índice de massa corporal, percentual de gordura corporal e gasto energético diário.

## Funcionalidades

- Cálculo do Índice de Massa Corporal (IMC).
- Estimativa do percentual de gordura corporal.
- Cálculo da Taxa Metabólica Basal (TMB).
- Cálculo do Gasto Energético Total (GET).
- Seleção de sexo.
- Seleção do nível de atividade física.
- Entrada de altura utilizando vírgula ou ponto como separador decimal.

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/escordotdev/calculadora-imc-java.git
```

2. Abra o projeto no IntelliJ IDEA.
3. Localize o arquivo principal `Main.java`.
4. Execute o método `main()`.
